01はじめに

ログインは社員番号と、会社メールに届く確認コード（6桁）で行います。一度ログインした端末は約30日間記憶され、次回からは自動でログインされます。

ログインの手順（初回・新しい端末のとき）

  1. アプリを開き、社員番号を入力して「確認コード送信」を押します。
  2. 会社のメールアドレスに6桁の確認コードが届きます（差出人「キンジロー君」）。
  3. そのコードを入力し、「この端末を記憶する」をONのまま「ログイン」を押します。
2回目以降は自動でログインされます 「この端末を記憶する」をONにしておくと、次回からはアプリを開くだけでコード入力なしで自動ログインします。記憶は約30日間で、使うたびに延長されるため、使い続ける限り実質ずっと記憶されます。
共有の端末では「記憶」をOFFに みんなで使う共有端末では「この端末を記憶する」をOFFにしてください（他の人が勝手に入れないようにするため）。自分専用のスマホではONのままでOKです。
確認コードは他人に教えないでください コードは自分のログイン専用です。メールが届かないときは迷惑メールフォルダをご確認ください。メールアドレスが登録されていない場合は管理部門にご連絡ください。

ログインできないとき

ログインに失敗すると、原因に応じたメッセージが赤い枠で表示されます。表示された内容にしたがって対応してください。

表示されるメッセージ原因と対処
サーバーが混み合っています。5分ほど時間をおいて、もう一度お試しください 始業前など、多くの人が同時に操作する時間帯に起こります。社員番号は間違っていません。5分ほど待ってからもう一度お試しください
通信に失敗しました。電波状況をご確認のうえ、もう一度お試しください 端末が通信できていません。電波の弱い場所や地下では届かないことがあります。場所を変えてお試しください
社員番号が見つかりません 入力した番号が登録されていません。番号をご確認ください。正しいのに表示される場合は管理部門にご連絡ください
メールアドレスが未登録です。管理部門にご連絡ください 社員マスタにあなたのメールアドレスが登録されていないため、確認コードを送れません。管理部門にメールアドレスの登録を依頼してください
コードが違います（残り○回） 入力した6桁が違います。メールに届いた最新のコードを確認して入力し直してください
コードの有効期限が切れました。再送してください コードには有効期限（約30分）があります。「コードを再送」から新しいコードを受け取ってください
誤入力が続いたためロックしました。コードを再送してください コードを何度も間違えたため、そのコードは無効になりました。「コードを再送」で新しいコードを受け取り直してください
○秒後にもう一度お試しください コードの再送は連続してできません。表示された秒数だけ待ってから再送してください

ホーム画面に追加すると便利です

ブラウザで開いたままでも使えますが、スマートフォンのホーム画面に追加するとアプリのように起動でき、自動ログインも安定します。自分のスマホでは、ホーム画面に追加して使うのがおすすめです。

  • iPhone（Safari）：共有ボタン → 「ホーム画面に追加」
  • Android（Chrome）：右上のメニュー → 「ホーム画面に追加」

021日の基本の流れ

迷ったらこの順番どおりに操作してください。

  1. 朝：種別を選ぶ（通常・フレックス・早出など）
  2. 朝：出勤ボタンを押す → 確認画面で内容を見て「打刻する」
    出勤の押し忘れに気づいたときは、まず出勤ボタンを押してください。 そのうえで、正しい出勤時刻を11 打刻修正申請から申請してください。 先に修正申請をして承認された場合でも、あとから出勤ボタンを押すとその打刻時刻で上書きされ、修正が消えてしまいます。
  3. 私用外出や時間外の移動があれば、その都度トグルをON/OFF
  4. 18時以降も勤務する場合は残業申請を行う
  5. 退勤前：稼働部門と実施内容を入力する
  6. 退勤ボタンを押す → 「打刻する」
退勤ボタンは出勤打刻をするまで押せません 出勤を打刻すると自動的に有効になります。

03出勤・退勤の打刻

ボタンを押すと確認画面が出ます。内容を確かめてから「打刻する」を押してください。

打刻時刻は1分単位で記録されます

ボタンを押した時刻がそのまま1分単位で勤務表に記録されます（15分などへの丸めはありません）。勤務時間の計算では、次の起点だけが決まっています。

打刻種別勤務時間の起点
出勤通常始業は9:00が下限（9時より前に出勤しても勤務は9:00から）
例：8時50分 出勤 → 9時00分から
早出 / フレックス実際の打刻どおり
例：8時38分 → 8時38分
退勤すべて実際の打刻どおり
例：18時05分 → 18時05分

位置情報について

打刻時に位置情報の許可を求められることがあります。許可すると打刻ログに記録されます。許可しなくても打刻は正常に完了しますが、位置情報の許可にご協力をお願いします。

打刻し忘れたときは その場では直せません。「各種申請」の打刻修正申請から申請してください。

呼び出しで再度出勤するとき（再出勤）

一度退勤したあと、同じ日に呼び出しで再び出勤したときに使います。もう一度だけ出勤・退勤を打てるようになります。

退勤を済ませると、ヘッダーの「各種申請」の左に 「再出勤」トグル が現れます（退勤していない日は出ません）。

  1. 再出勤トグルをONにする → 出勤ボタンが再び押せるようになり、画面に対象の勤務日（例：8/4）が表示されます
  2. 出勤ボタンを押す → 前回の退勤から今までの空き時間が、自動で規定外休憩に加算されます
  3. 呼び出しの作業が終わったら 退勤ボタンを押す → その日の勤務表に反映されます
空き時間は規定外休憩として扱われます 前回の退勤から再出勤までの時間（例：18:00〜21:00 の3時間）は、働いていない時間として規定外休憩に入り、稼働時間からは差し引かれます。
0時をまたいでも「その日の勤務」として記録されます 再出勤や退勤が深夜0時を過ぎても、日付は元の勤務日のまま記録されます。深夜の退勤は 25:00・26:00 …（＝翌1:00・翌2:00）のように表示されます。
例：8/4 に出勤・退勤 → 深夜に呼び出し → 8/5 の 2:00 に退勤、の場合、8/4 の行に「退勤 26:00」として入ります。
再出勤トグルが使えるのは翌朝5:00までです 呼び出しは深夜までを想定しています。翌朝5:00を過ぎるとトグルは消え、通常の新しい勤務として扱われます。翌朝の通常出勤はトグルをOFFのまま出勤してください。

04種別の選び方

出勤打刻の前に必ず選びます。選ばないと出勤ボタンを押せません。

種別使う場面
通常9:00から業務を開始する場合
早出9:00より前に業務を開始する場合
遅出9:00より後に業務を開始する場合（遅刻は含みません）
フレックスコアタイム内で8時間勤務する場合
例：8:00〜17:00、10:00〜19:00 など
有給(午前) / 有給(午後)半日だけ有給を取って残りは勤務する日
振休(午前) / 振休(午後)半日だけ振替休日を取る日
代休(午前) / 代休(午後)半日だけ代休を取る日
まる1日休む場合はここでは選びません 1日まるごとの有給・振休・代休・欠勤などは、打刻画面ではなく休暇・欠勤申請から申請します。

「通常」「フレックス」を選んだ場合は次回ログイン時に自動で復元されます。

05規定外休憩・時間外移動

勤務時間から差し引く時間を、その場で計測するための機能です。

規定外休憩

私用外出や、通常の休憩時間以外に取った休憩を記録します。

  • 外出するときにカードをタップしてON
  • 戻ったらもう一度タップしてOFF
  • 合計時間が「計 ◯分」と表示されます

時間外移動

18時以降の移動時間など、残業の対象にしない時間を記録します。

  • 移動を始めるときにON、着いたらOFF
1分単位で計上されます ON/OFFで計測した合計時間が、そのまま1分単位で勤務表に反映されます（丸めはありません）。
OFFに戻し忘れに注意してください ONのままだと時間が加算され続けます。退勤打刻の前に必ずOFFになっているか確認してください。

あとから時間を直したいとき（規定外休憩／時間外移動 修正）

トグルのON/OFFを忘れた・時間がずれていた場合は、ヘッダーの「各種申請」の中の 「規定外休憩／時間外移動 修正」から、あとで時間を直せます。

  1. 修正対象を選ぶ（規定外休憩 または 時間外移動）
  2. 対象日付を選ぶ（本日まで）
  3. 時間を入力する（時:分・1分単位・最大12:00。0:00＝なしにするとその日の値を消せます）
  4. 「修正する」を押すと、その日の勤務表の値が上書きされます
承認は不要・すぐに反映されます 「修正する」を押した時点で勤務表に直接反映されます。加算ではなく上書きなので、その日の最終的な合計時間を入れてください（例：合計1時間30分なら「1:30」と入力）。
修正した記録は残ります いつ・どの項目を・何時間に直したかは、勤務表の「申請」シートに履歴として自動で記録されます。

06稼働情報

その日どこで何をしたかを記録します。退勤打刻のときに必須です。

  • 遠地：遠地で勤務した日だけONにします（次で説明。通常はOFF）
  • 稼働部門：その日稼働した部門をリストから選びます
  • 実施内容：作業内容を具体的に入力します（例：顧客訪問、社内会議、現場作業）
退勤前に内容を確認してください 勤務表へ書き込まれるのは退勤打刻のタイミングです。

稼働部門は次回ログイン時に前回の選択が復元されます。

遠地（遠地で勤務した日）

遠地で勤務した日だけ使います。ふだんはOFFのままです。

  1. 遠地で勤務した日は、「遠地」のトグルをONにします
  2. そのまま退勤ボタンを押すと、勤務表のその日の備考欄に「遠地」が追記されます
備考は上書きせず「追記」されます もともと備考に記載がある場合は消さずに追加されます。遠地でない日はトグルをOFFのままにしてください。

07残業申請

18時以降も勤務する場合は、上長へ申請・報告します。

  1. 「各種申請」を開き、いちばん上の残業申請を押します
  2. 想定残業時間（何時まで勤務するか）を選びます
  3. 作業内容・理由を入力します（必須）
  4. 「申請する」を押すと上長にメールが届きます
申請するとボタンが「残業申請済み」に変わります 退勤打刻をすると元に戻ります。1日1回申請すれば大丈夫です。

08休暇・欠勤申請

これから取る休暇を事前に申請します。上長が承認すると勤務表に反映されます。

  1. 申請種別を選びます（有給・振休・代休・明休・欠勤・特別・慶弔）
  2. 休暇時間を選びます（全休・午前休・午後休）
  3. 開始日と終了日を選びます。1日だけなら同じ日付にします
  4. 備考に理由を入力します（必須）
  5. 「申請する」を押します
本日以降の日付しか選べません 土日も選べません。過ぎた日の休暇は管理部門にご相談ください。
月をまたぐ申請もできます 8月28日から9月3日のような期間でも、承認されればそれぞれの月の勤務表に反映されます。期間内の土日・祝日は自動で除かれます。

上長が承認または却下すると、結果がメールで届きます。勤務表に反映されるのは承認された後です。

09休日出勤申請と振替休日

土日祝に出勤する場合は、事前に申請して上長の承認を得てください。

  1. 対象日付（出勤する休日）を選びます
  2. 振替休日の取得を選びます
  3. 申請理由を入力します（必須）
  4. 「申請する」を押します

振替休日の指定

選択肢内容
申請しない振替休日を取らず、休日出勤として扱います
全休で1日取得別の日を1日まるごと休みにします。振休日を1つ指定します
半休を2回に分けて取得2つの日をそれぞれ午前休・午後休にします。日付と時間帯を2組指定します
振替休日を指定すると、その休日出勤は平日と同じ計算になります 休日労働ではなく通常の勤務日として扱われ、指定した振休日が休みになります。振替休日を指定しない場合は休日出勤として集計されます。

承認されると

  • 休日出勤日の備考に「上長名：承認済み」と「◯/◯に振休予定」が入ります
  • 振休日には種別が自動でセットされ、備考に「◯/◯の振休消化」が入ります
  • 振休日が翌月でも、その月の勤務表に反映されます
申請せずに休日出勤すると警告メールが届きます 土日祝に出勤打刻をした時点で休日出勤申請が承認されていない場合、本人あてに確認メールが自動送信されます。事前申請をお願いします。

10在宅申請

在宅勤務をする場合に申請します。上長が承認または却下するとメールで通知されます。

  1. 業務内容を入力します（必須）
  2. 日付を指定します。単日・期間指定・毎週◯曜日の3通りから選べます
  3. 時間を入力します（任意）
  4. 就業場所を選びます。「自宅に準じる場所」を選んだ場合は具体的な場所も入力します
  5. 申請理由を選びます。「その他」を選んだ場合は詳細も入力します
  6. 「申請する」を押します
当日の在宅は打刻画面のトグルで記録します 打刻画面の「在宅」トグルをONにして出勤打刻すると、その日の備考に「在宅」と記録されます。在宅申請とは別の機能です。

11打刻修正申請

打刻を忘れた、時刻を間違えたときに使います。上長が承認すると勤務表が書き換わります。

  1. 対象日付を選びます（本日まで。未来の日付は選べません）
  2. 修正対象で「出勤」か「退勤」を選びます
  3. 修正時間を入力します（必須）
  4. 修正理由を入力します（必須）
  5. 「申請する」を押します
1回の申請で直せるのは出勤・退勤のどちらか一方です 両方を直したい場合は、出勤と退勤で2回申請してください。

承認されると勤務表の時刻が書き換わり、備考に「上長名：修正」と記録されます。

12勤務表の確認

当月の勤務表をPDFで受け取れます。

  1. 「各種申請」を開き、勤務表確認の「PDFをメールに送信する」を押します
  2. 登録されているメールアドレスにPDFが届きます
生成に少し時間がかかります ボタンを押してからメールが届くまで数十秒かかることがあります。何度も押さずにお待ちください。

13自動で届くメール

操作しなくても届くメールがあります。内容を確認して対応してください。

勤怠確認のお願い

出勤から9時間10分が過ぎても退勤打刻も残業申請もない場合に届きます。退勤打刻を忘れていないか、残業申請が必要かを確認してください。

休日出勤申請未完了のお知らせ

土日祝に出勤打刻をしたのに、休日出勤申請が承認されていない場合に届きます。速やかに申請してください。

申請の承認・却下通知

提出した申請を上長が処理すると届きます。却下された場合は理由を上長に確認してください。

勤務表承認のお知らせ

月末締めのあと、上長が勤務表を承認すると前月分の勤務表PDFが添付されて届きます。内容を確認してください。

14よくある質問

出勤ボタンが押せません
種別が選択されていない可能性があります。「種別」欄で通常などを選んでから押してください。すでに本日の出勤打刻が済んでいる場合もボタンは押せなくなります。
退勤ボタンが押せません
出勤打刻が済んでいないと押せません。出勤を打刻し忘れた場合は、まず出勤ボタンを押してから、11 打刻修正申請で正しい出勤時刻を申請してください。
退勤しようとしたら「稼働部門を選択してください」と出ます
稼働部門と実施内容は退勤時に必須です。画面下部の「稼働情報」の両方を入力してから退勤ボタンを押してください。
打刻した時刻と勤務表の時刻が違います
打刻時刻は1分単位でそのまま記録されます（丸めはありません）。ただし通常の始業は9:00が下限で、9時より前に出勤しても勤務は9:00からになります（早出・フレックスは実際の打刻どおり）。詳しくは03 出勤・退勤の打刻をご覧ください。
申請したのに勤務表に反映されません
休暇・休日出勤・打刻修正はいずれも上長が承認してから反映されます。承認されると本人にもメールが届きますので、まだ届いていない場合は上長にご確認ください。
間違えて申請してしまいました
アプリから取り消す機能はありません。上長に連絡して却下してもらうか、管理部門にご相談ください。
スマートフォンを変えました。データは残りますか
打刻データはサーバー側に保存されているので残ります。新しい端末でログインすれば当日の打刻状況が表示されます。種別や稼働部門の「前回の選択」は端末ごとの記憶なので引き継がれません。
通信エラーと表示されました
